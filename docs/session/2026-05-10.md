# 2026-05-10

## Updated ComfyUI

Updated ComfyUI using comfy-cli:

```bash
pip install "comfyui-manager>=4.1b1"
comfy --workspace "$(pwd)/comfy-managed" update comfy
```

## Fix: "cm-cli not found" warning

After the update, ComfyUI Manager showed `Failed to update node id cache: cm-cli not found`.

Root cause: `comfy update` tries to run `cm-cli` to rebuild the node cache, but it's only available as a command starting from `comfyui-manager>=4.1b1`. Installing that version via pip makes `cm-cli` available in the venv and resolves the warning.
